## 移植差异

1. `models/root.ts`：存储常量指向 DSH 数据目录，由宿主接口映射实际磁盘路径。
2. `store.ts`：取消向 Obsidian 兼容副本写入；读取失败不会被误判为空库。
3. `views/dashboard.ts`：背景直接内嵌原图，复盘使用异步文件接口，打开目录通过宿主执行；保留原页面结构。
4. `kanban/sync.ts`：同名任务或已有手写笔记发生文件名冲突时，以任务 ID 区分文件，防止覆盖，并支持再次同步。

5. `views/base.ts`：去掉内部左列和独立主题选择，保留八个业务页签。
6. `design-system/theme.ts`：页面与弹窗的明暗模式跟随 DSH。

7. `design-system/select.ts`：菜单尺寸按内容、触发按钮和屏幕边界计算。

`shim/` 提供 Obsidian DOM、弹窗、菜单、工作区、主题和文件 API 的 DSH 适配。宿主接口使用 DSH 的登录鉴权；写入路由使用支持 POST 的 handler，不使用只能处理 GET/HEAD 的 resource 路由。
